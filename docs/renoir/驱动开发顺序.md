# renoir 驱动开发顺序

2026-10-22。执行节奏：每版两个明确目标，采用“两个驱动”或“一个驱动＋一个问题修复”。硬件前置验证是驱动的一部分，探测通过不能宣称完整驱动完成。每个功能有独立开关；回归时单独关闭，保留已验证镜像。

| 批次 | 目标一 | 目标二 | 验收及依赖 |
| --- | --- | --- | --- |
| 已通过 0096 | 专用映射后的GPI NOP DMA验证 | 修复FSR格式位被误当fault导致立即退出 | 100µs内收到有效事件，无真实fault |
| 已通过 0097 | SPI会话GSI LOCK/UNLOCK | 完成事件逐项校验，失败停止后续提交 | 三项100µs完成，guard1/faults0 |
| 当前 0098 | GSI SPI读取FT3658U ID | 双通道事件顺序与CRC校验 | 本地98补丁/编译通过；CI39761164996，真机待验 |
| 后续一 | FT3658U SPI 芯片 ID、坐标及 HID 接入 | 锁屏字体颜色排查修复 | 先验证电源/时钟、稳定 ID，再验收点击/上滑/抬手；颜色需照片与纯色图定位 |

| 单独研究 | GPU/图形加速 | 根据研究结果安排 | Adreno＋iOS 图形接口工作量大，不承诺一版完成，不阻塞先完成基本操作 |

触控依赖复杂时，按 SPI 状态→电源/时钟→芯片 ID→坐标→HID 分阶段，每版将可验收阶段与一个独立修复搭配，避免把未测代码一次堆到手机。

已验证基线：0088（保留0087时间修复），真实锁屏、电源/音量键和本地时间正常；用户确认 10Hz 比 30Hz 反馈明显改善。触控供电请求和复位已验证；FIFO禁用已确认，须先移植GSI/DMA，芯片ID仍未读取。没有触控事件、GPU、真实电池遥测。颜色问题目前只有用户描述；用户认为与无 GPU 软件渲染有关，这是候选解释，尚未验证。

启动、日志和构建命令见 [启动与驱动移植交接指南](启动与驱动移植交接指南.md)。真机测试只临时启动、不重刷 userdata；新破坏性刷写需另行确认。每版记录源码提交、CI、哈希、用户实测结果；QEMU按2026-10-22用户要求跳过。
